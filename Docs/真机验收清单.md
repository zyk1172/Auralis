# Auralis 真机验收清单（对应审计「尚未验证」节）

> 环境限制：本开发环境无真机 / 无签名 / 无真实服务器，以下项目需在真机 + 真实 Navidrome（或兼容 OpenSubsonic 服务器）上验证。
> 前置：Xcode 打开 Auralis.xcodeproj → 选择你的开发者团队 → 真机运行（iOS 26+）。

## 一、控制中心与锁屏

- [ ] 播放任意歌曲后，控制中心 / 锁屏显示：歌名、艺术家、专辑、封面、总时长、进度、播放状态
- [ ] 切歌后控制中心立即更新为新歌曲
- [ ] 封面晚到：先显示文字与状态，封面加载完成后补充（不出现空白）
- [ ] 控制中心可执行：播放 / 暂停 / 继续 / 上一首 / 下一首 / 拖动进度
- [ ] 随机 / 循环按钮状态与 App 内一致
- [ ] 关闭全屏播放器 / 切换 Tab / 进入后台后，控制中心歌曲信息不清空
- [ ] 拖动进度后，App 与锁屏进度一致
- [ ] 队列位置 / 总数在支持的系统 UI 中显示正确

## 二、后台持续播放

- [ ] 开始播放 → 返回主屏幕 / 锁屏 / 关屏，持续播放（至少 30 分钟）不停止
- [ ] 切换本 App 页面、关闭全屏播放器、隐藏迷你播放条不停止
- [ ] 锁屏状态下自动切下一首，队列正常推进
- [ ] 后台长时间播放后播放器对象仍存活（无「停止原因=播放器被释放」）

## 三、音频中断与设备

- [ ] 来电 / FaceTime：暂停；挂断后按系统建议恢复
- [ ] 拔出耳机 / 断开蓝牙：暂停（不突然从扬声器出声）
- [ ] 重新插回耳机：不无故停止，继续正常输出
- [ ] AirPlay 切换后状态同步，控制中心正确
- [ ] 静音开关不影响播放

## 四、Siri / 快捷指令 / Spotlight

- [ ] 语音：「用这个 App 播放七里香」「播放周杰伦的歌」「播放我的收藏」「播放最近听过的音乐」「继续播放」「下一首」「暂停音乐」
- [ ] 快捷指令 App 中可运行：播放或暂停 / 下一首 / 上一首 / 播放我的收藏 / 播放最近 / 播放随机 / 切换随机 / 播放歌曲 / 设置睡眠定时 / 同步音乐库
- [ ] Spotlight 搜索歌曲 / 专辑 / 艺术家 / 歌单可打开对应实体
- [ ] Siri 播放后 App、控制中心、锁屏、迷你播放条、队列一致
- [ ] Siri 播放后 App 被杀再启动，队列/进度恢复但不自动出声

## 五、资料库持久化与同步（真机 + 服务器）

- [ ] 首次连接并同步完成后，完全退出并重开 App：音乐库立即从本地显示（不等待网络）
- [ ] 断开服务器后重开：仍可浏览歌曲/专辑/艺术家/歌单/收藏/封面/歌词
- [ ] 重连服务器：只同步变化内容（新增/修改/删除），不重下全库
- [ ] 同步失败后重开：保留上次成功数据
- [ ] 两台服务器数据隔离：切换服务器后不混用同 ID 歌曲；封面/播放次数/收藏不串
- [ ] 同一封面再次进入各页面不重复下载（断网重开仍显示已缓存封面）
- [ ] 已获取歌词再次播放直接读取本地，不重复请求

## 六、离线下载与缓存

- [ ] 下载单曲 / 专辑 / 艺术家（批量）后离线可播放
- [ ] 下载中显示进度，可取消
- [ ] 下载被打断/App 挂起后，按系统规则继续或可重试
- [ ] 清理封面/歌词缓存不影响离线音乐；清理音频缓存会删除下载
- [ ] 设置页各缓存容量与清理正常

## 七、播放功能回归

- [ ] 单曲/专辑/歌单/收藏/随机/搜索在线结果播放正常
- [ ] 上一首/下一首/暂停/继续/停止/快进 30 秒/后退 15 秒/拖动进度正常
- [ ] 单曲循环/列表循环/关闭循环/随机播放/恢复顺序正常
- [ ] 播放速度 0.5x–2.0x 生效且控制中心速率一致
- [ ] 睡眠定时：若干分钟后 / 当前歌曲 / 当前专辑 / 当前队列结束后停止
- [ ] 流地址失效（服务器重启/重启 App 后继续播放旧流）时自动刷新重试或自动下一首
- [ ] 拔网/断 Wi-Fi 后播放失败提示提供「重试 / 下一首 / 重新登录」可恢复操作

## 八、灵动岛

- [ ] 播放时灵动岛出现紧凑/极简形态，显示音乐图标与播放状态
- [ ] 切歌/暂停/进度更新同步到灵动岛
- [ ] 停止播放/移除服务器/睡眠定时结束时灵动岛消失
- [ ] 锁屏实时活动卡片显示标题/艺术家/进度/状态

## 九、AI 助手自然语言验收

- [ ] 「播放周杰伦的七里香」（本地匹配 → 播放，多结果时给出候选）
- [ ] 「播放周杰伦最常听的十首歌」（library_get_most_played）
- [ ] 「找几首适合深夜听的歌」（recommend_by_mood → 真实曲目卡片）
- [ ] 「播放我的收藏」「下一首」「跳到两分三十秒」「开启单曲循环」
- [ ] 「这首歌加入下一首播放」「把当前队列保存成歌单」
- [ ] 「我有哪些 Adele 的专辑？」「最近一个月添加了哪些歌曲？」（library_get_recently_added）
- [ ] 「哪些歌从来没有播放过？」（library_find_metadata_issues / getLeastPlayed）
- [ ] 「收藏里有哪些 FLAC？」（recommend_by_constraints losslessOnly+favoritesOnly）
- [ ] 「下载这张专辑」（downloadAll + 批量下载确认）
- [ ] 「清理临时音频缓存」（cache 清理）
- [ ] 「为什么刚才停止播放了？」（diagnostics_playback / 停止原因）
- [ ] 「控制中心显示的歌曲对不对？」（diagnostics_now_playing）
- [ ] 「服务器现在是否在线？」「同步进行到哪里了？」（server_test_connection / server_sync_status）
- [ ] 清空/替换队列、切换服务器、删下载等普通操作直接执行；删除歌单以及清空/删除记忆或技能文件时出现一次明确批准，并验证拒绝不会产生副作用
