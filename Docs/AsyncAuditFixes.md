# 异步状态审查修复

本轮对应 2026-10-02 审查中的 F01–F12，并修复验证中新发现的 AV 引擎协议默认实现遮蔽问题，保持现有 Dock 和播放界面结构。

| 问题 | 修复边界 | 自动验证 |
| --- | --- | --- |
| F01/F02：歌单下标失效和跨服务器回流 | GlobalID 缓存、每歌单操作串行、会话代际、返回后重新定位、持久化读取最新值 | 连续排序、切库后排序/删除/加载返回 |
| F03：下载旧回调覆盖重试 | URLSession taskIdentifier 所有权校验、安装前检查、仅清理自身安装的文件 | 旧成功/失败回调、新文件保护、拒绝过期安装 |
| F04：恢复越过用户停止/选曲 | 播放意图代际、可取消的恢复任务、停止状态立即生效、停止任务提交守卫 | 手动重试期间换歌、自动恢复期间停止 |
| F05：备份配置与凭据混用 | 缺少 Key/Token 清理旧凭据、写入失败回滚、成功后提交公开设置 | 缺少凭据、第二个凭据失败后的回滚 |

## 验收范围

自动测试主要保证身份、顺序、取消和失败语义；听音质量、蓝牙/来电中断、锁屏续播、真实下载恢复、滚动帧率及功耗仍需设备验收。不得把编译成功解释为这些场景已经通过。

F13 是 App Store 发布条件下的隐私声明专项，本轮不填入未经完整数据流核验的理由清单。发布前需要核对实际 API 用途、AI 工具输出和归档产物，再完成 PrivacyInfo.xcprivacy；文件存在本身不代表声明正确。
