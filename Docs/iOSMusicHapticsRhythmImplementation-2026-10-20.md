# iOS 音乐节奏触觉实现

本次改动基于 [审查和研究方案](iOSMusicHapticsRhythmPlan-2026-10-19.md)，使用独立分支 `codex/ios-music-haptics-rhythm`。

## 实现范围

- 事件携带逐拍音乐角色、置信度、拍点和周期；缓存、checkpoint、窗口裁剪、去重、碰撞融合与鼓点 body 保留这些信息。算法版本升级至 `auralis-haptics-v4.1`，旧版本缓存重新生成。
- 真实起音支持的主拍使用独立声部，不消耗装饰音密度、间隔和疲劳预算。一个碰撞窗口最多保留一个主拍声部和一个原有细节声部；近邻高帽等细节保留自己的时间、音色。同类同次攻击仍去重，缓存合并使用同一分层规则。
- 跟踪器支持已锁定网格上的弱起音、多个周期/相位假设、跨起音间隔、能量加权的主拍证据、温和相位修正、重复拍抑制、证据超时及 seek 重置。保留原曲起音时间，不强制量化或假设 4/4；没有加入自由运行的节拍器。
- 本地“节奏清晰 / 音乐沉浸”和“轻 / 中 / 强”在渲染阶段应用。两种风格完整保留原有持续纹理包络和装饰细节；节奏清晰仅为主拍增加剩余强度空间的 12%，音乐沉浸使用原有主拍强度。不再全局衰减纹理、高帽或在拍点附近做侧链挖空。轻档只改变总体力度，纹理与攻击使用相同倍率，各档共用 0.03 的近零过滤线。曲线与鼓点仍使用隔离的 pattern，窗口边界继续插值。
- 设置提供两秒试听、停止试听和恢复默认；音乐播放时禁止试听，正常播放开始时取消试听任务，避免旧任务打断后续音乐。
- AVPlayer 周期位置携带单调时钟采样时刻；异步窗口输出时外推到当前歌曲位置。权威播放采样建立后，UI 估计不会覆盖它。暂停、seek 和变速重建锚点。
- 窗口输出报告提交、过滤、过期、容量拒绝、不可用或失败；拒绝时恢复滚动调度游标，仅重试仍在未来的事件。诊断提供提交主拍数、拒绝次数、原因、风格与力度。
- 观察当前 ISRC 的系统 Music Haptics 实际播放状态；系统接管时停止本地输出。单次停止回调不立即开启第二条触觉链路，下一次 preparation 重新仲裁。系统轨道的风格/力度仍由系统设置管理。

## 验证

新增回归覆盖节拍元数据持久化与旧 JSON、弱主拍与碰撞、去重、纹理完整保留与跨窗口连续性、窗口边界插值、多种速度、弱起音、静默、swing、倒退 seek、延迟时钟、拒绝重试、设置持久化、试听取消与系统接管。

新增分层回归对比同一段 20 秒候选流添加主拍前后：原有细节事件和纹理曲线逐项一致，主拍独立保留；检查 501 个纹理采样点不受密集拍点削弱、轻档保留弱细节和渐强纹理、重复缓存合并保留两个声部、同次攻击不重复。旧 v4.0 缓存会失效并重新分析，避免继续使用已经丢失细节的时间线。

横屏切页交互检查还会在测试专用开关下，短时采样原生滚动视图的 presentation bounds，补充可能合并为端点的 SwiftUI 逻辑几何回调。保留“实际经过横向中间位移”的断言，失败信息同时报告逻辑位置、呈现位置和采样数；此探针不进入 Release。

Apple 编译、Swift 测试和模拟器交互以本 PR 对应最新提交的 Apple CI 结果为准。

## 横屏切页验证

原生呈现采样复现横屏位置从 1000 直接跳到 0，17 次采样未经过中间位置，确认原有命令式切页存在硬切。分页改用独立的 `ScrollPosition` 绑定，在同一动画事务内写入目标 ID；只有用户横向滚动完成后回写页面选择，避免把中间页反馈到控件状态。初始目标由位置值与布局锚点建立，不引入定时等待，歌词纵向滚动与控制栏手势链路保持独立。

API 使用依据：[Apple ScrollPosition](https://developer.apple.com/documentation/swiftui/scrollposition)。原有 UI 中间位移断言与原生呈现采样继续验证新路径。无障碍可访问页在原生滚动结束后更新，避免切页起始时隐藏正在操作的横屏按钮；减少动态效果时即时更新。采样在原生侧累积，只在观察到中间位移或超时后向 SwiftUI 汇报一次，并记录首帧耗时，避免逐帧状态写入反过来干扰被测动画。

## 仍需真机验收

模拟器与软件事件测试不能证明皮肤上的同步、舒适性或更受用户喜爱。按研究方案验证真实声音/振动延迟、扬声器/有线/蓝牙、手机壳/握持、锁屏与系统实际暂停、连续 20–30 分钟舒适性、耗电与温升。

iOS 真机反馈指出初版空白过多、层次不足：默认纹理曾被全局缩至 38%，拍点附近进一步缩至约 11%，主拍还挤占了细节预算。这些削弱策略已移除；“叠加且不删减原有层次”作为本次修正的验收要求。软件回归不能替代同一歌曲的真机复听。预测补拍、Core ML 拍号/downbeat 模型和用户研究中的偏好结论未作为已经完成或已经有效的功能发布。
