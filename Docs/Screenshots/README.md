# Screenshot policy

Store only reviewed, synthetic product screenshots here using these names:

- `iphone-home.png`
- `iphone-now-playing.png`
- `ipad-three-column.png`
- `mac-library.png`
- `mac-ai-workbench.png`
- `theme-gallery.png`

Do not add screenshots containing real server URLs, usernames, local paths, API keys, private
library metadata, personal desktop content, or identifiable copyrighted album artwork. Audio
shown in a screenshot must be a generated or explicitly redistributable test fixture. A screenshot
is not a substitute for device, accessibility, audio, or network acceptance evidence.
