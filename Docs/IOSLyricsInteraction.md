# iOS 歌词滚动与页面切换

歌词使用原生竖向 ScrollView 的拖动速度和减速行为。没有用固定行数、固定滑动距离或动画时长代替手势惯性，也不在歌词外层增加争抢竖向手势的 DragGesture。

播放跟随通过 ScrollViewReader 单向定位当前行，不把用户正在浏览的位置双向绑定回程序定位目标。触摸、拖动及减速期间暂停自动跟随；原生滚动结束五秒后，才平滑定位到最新播放行。

底部选项的显隐直接读取原生拖动中的竖向偏移：上滑达到 44pt 即开始收缩，下滑达到 44pt 即开始展开，不等待松手或惯性结束。同一次拖动反向也能切换。选项动画引起的视口尺寸和偏移变化不计入手势距离，避免布局反馈造成反复显隐；松手后的惯性和播放定位也不重复触发显隐。原有平滑动画、五秒无操作自动隐藏及停止浏览后恢复跟随的规则保留。

竖屏及横屏的歌词、封面/控制、队列页面使用同一个原生横向分页容器。每页宽度取分页容器自身的可用宽度，横屏时限定在右侧内容栏。原生初始滚动锚点按创建时所选页面确定位置，避免首次定位任务早于布局而失效。按钮通过 ScrollViewReader 单向发出带动画的定位命令；原生横向手势结束后才把落定页面写回选择状态，避免中间滚动位置覆盖按钮目标并取消动画。减少动态效果开启时遵循系统设置。

回归验证检查实际滚动几何：拖动后保持手指按住，要求底部选项收缩和展开造成的视口尺寸变化已在拖动阶段发生；比较慢滑与快滑松手后的减速距离，要求快滑明显更远；点击歌词按钮时，要求记录到动画中的非整页横向偏移，不能仅凭按钮选中状态认定动画存在。已有播放过程中手动浏览不被自动跟随抢走位置的 UI 用例继续保留。仅 DEBUG UI smoke 启用测量，不改变生产滚动参数或浏览时限。
