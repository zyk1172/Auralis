# iOS 歌词滚动与页面切换

歌词使用原生竖向 ScrollView 的拖动速度和减速行为。没有用固定行数、固定滑动距离或动画时长代替手势惯性，也不在歌词外层增加争抢竖向手势的 DragGesture。

播放跟随通过 ScrollViewReader 单向定位当前行，不把用户正在浏览的位置双向绑定回程序定位目标。触摸、拖动及减速期间暂停自动跟随；原生滚动结束五秒后，才平滑定位到最新播放行。Chrome 显隐方向从原生滚动起止偏移判断，在减速完成后改变布局。

竖屏及横屏的歌词、封面/控制、队列页面使用同一个原生横向分页容器。底部按钮和手势操作同一个分页位置；按钮以平滑动画切换，减少动态效果开启时遵循系统设置。

回归验证检查实际滚动几何：比较慢滑与快滑松手后的减速距离，要求快滑明显更远；点击歌词按钮时，要求记录到动画中的非整页横向偏移，不能仅凭按钮选中状态认定动画存在。已有播放过程中手动浏览不被自动跟随抢走位置的 UI 用例继续保留。仅 DEBUG UI smoke 启用测量，不改变生产滚动参数或浏览时限。
